# Sistema de Videotienda

## Descripción
Sistema de gestión para una videotienda desarrollado en Java utilizando el patrón MVC (Modelo-Vista-Controlador) y principios de Programación Orientada a Objetos (POO).

## Características
- Gestión de películas
- Gestión de clientes
- Sistema de alquiler
- Gestión de devoluciones
- Reportes y estadísticas

## Tecnologías Utilizadas
- Java
- MySQL
- JDBC
- Swing (GUI)

## Estructura del Proyecto
```
n4_videotienda/
├── src/
│   ├── modelo/
│   │   ├── Pelicula.java
│   │   ├── Cliente.java
│   │   └── Alquiler.java
│   ├── vista/
│   │   ├── VentanaPrincipal.java
│   │   └── componentes/
│   └── controlador/
│       └── Controlador.java
├── lib/
│   └── mysql-connector-java.jar
└── README.md
```

## Requisitos
- Java JDK 8 o superior
- MySQL Server
- IDE compatible con Java (recomendado: Eclipse)

## Instalación
1. Clonar el repositorio
2. Importar el proyecto en Eclipse
3. Configurar la base de datos MySQL
4. Ejecutar el script SQL para crear las tablas necesarias
5. Compilar y ejecutar el proyecto

## Uso
1. Iniciar la aplicación
2. Ingresar con las credenciales de administrador
3. Navegar por el menú principal para acceder a las diferentes funcionalidades
